
# 📍 Map Location - Live Location Tracking

A real-time location tracking web application built using Node.js, Express.js, Socket.IO and Leaflet.

## 🚀 Live Demo
https://map-location-mx8e.onrender.com

## ✨ Features
- Real-time location tracking
- Interactive map using Leaflet
- Socket.IO communication
- Live location updates
- Responsive interface

## 🛠️ Tech Stack
- Node.js
- Express.js
- Socket.IO
- Leaflet.js
- HTML, CSS, JavaScript

## 💻 Installation

```bash
git clone https://github.com/Abhiverma1-max/map-location.git
cd map-location
npm install
npm start
```
